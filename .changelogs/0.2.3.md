# BetterFurnaceNH 0.2.3

## 中文

- 发布 Modernity 适配材质包，提供熔炉漏斗输入/输出开关的 Modernity 风格材质。
- 适配包封面与 BackpackEnhance 统一外框、配色和中央按钮样式，中央字母使用 `F`。
- Gradle 构建自动生成 `Modernity-BetterFurnaceNH-0.2.3.zip`，与正式、开发、源码 JAR 一起发布到同一个 Release。
- 规范发布流程：创建 PR，等待 CI 通过，合并 PR，等待主分支 CI 通过，再通过版本标签发布。发布工作流自动验证合并提交和主分支 CI。
- starter/migration 开发模板改为手动导出工作流附件。

安装适配包：将 `Modernity-BetterFurnaceNH-0.2.3.zip` 放入游戏 `resourcepacks/`，启用后置于 Modernity 上方。

## English

- Ship a Modernity adapter for the furnace hopper input/output toggle textures.
- Match BackpackEnhance's Modernity cover style with an `F` in the central button.
- Package the Modernity ZIP during Gradle builds and publish it alongside the regular, development and sources JARs in the same release.
- Standardize releases through PR creation, successful CI, PR merge, successful master CI and a bare version tag. The release workflow verifies the merged commit and its CI.
- Export starter/migration development templates manually as workflow artifacts.

Install the adapter by placing `Modernity-BetterFurnaceNH-0.2.3.zip` in the game's `resourcepacks/` directory and enabling it above Modernity.
