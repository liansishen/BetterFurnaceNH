# BetterFurnaceNH 0.2.4

## 中文

- 修复燃料槽处理堆叠流体单元时，只填充一个单元的流体却丢失整叠物品的问题。现在逐个处理，并保留剩余满单元。
- 通过流体容器注册表返还空容器。堆叠中产生的空容器进入输出槽，最后一个空容器留在燃料槽。
- 流体槽容量不足以容纳整个单元，或输出槽无法接收空容器时，暂停处理并保留物品与流体。
- 底部漏斗升级和熔炉下方的普通漏斗支持输出燃料槽中的空单元、空桶等已注册空流体容器，保留满单元和固体燃料。
- 底部漏斗升级优先输出成品，遵守传输间隔、开关和目标容器的插入限制；目标满载时保留待输出物品。

安装：将模组 JAR 放入游戏的 `mods/` 目录并重启；多人游戏的服务端也需要更新。

Modernity 适配包：将 `Modernity-BetterFurnaceNH-0.2.4.zip` 放入 `resourcepacks/`，启用后置于 Modernity 上方。

## English

- Fix stacked fluid containers disappearing from the fuel slot after only one container's fluid is transferred. Process one container at a time and preserve the remaining filled containers.
- Return empty containers through the fluid container registry. Empties from a stack go to the output slot; the final empty remains in the fuel slot.
- Preserve items and fluid when the tank cannot hold a complete container or the output slot cannot accept its empty container.
- Allow the bottom Hopper Upgrade and a vanilla hopper below the furnace to extract registered empty fluid containers, including empty cells and buckets, from the fuel slot. Preserve filled containers and solid fuel.
- Keep product output priority, transfer timing, upgrade toggles and destination insertion restrictions. Preserve pending items when the destination is full.

Install the mod JAR in the game's `mods/` directory and restart. Multiplayer servers also need the update.

For Modernity, place `Modernity-BetterFurnaceNH-0.2.4.zip` in `resourcepacks/` and enable it above Modernity.
