# Modernity — BetterFurnaceNH

适用于 Minecraft 1.7.10 的 BetterFurnaceNH Modernity 适配包，提供熔炉漏斗输入/输出按钮的 Modernity 风格材质。

将本目录或发行 ZIP 放入游戏 `resourcepacks/`，启用后置于 Modernity 上方。按 F3+T 可重新加载。ZIP 的 `pack.mcmeta`、`pack.png` 和 `assets/` 位于根目录。

## 内容与来源

- `assets/betterfurnacenh/textures/gui/buttons/` 包含四张 18×18 RGBA 按钮图片，分别对应输入/输出的开启与关闭状态；模组按 16×16 显示。
- 材质风格与封面外框来自 [ModernityGTNH / Modernity-GTNH-UI 2.9.X](https://github.com/ModernityGTNH/Modernity-GTNH-UI/tree/2.9.X)，作者与贡献者见上游项目。
- `pack.png` 参考 [BackpackEnhance Modernity 适配包](https://github.com/liansishen/BackpackEnhance/tree/main/resourcepacks/Modernity-BackpackEnhance) 的中央 `B` 按钮，保留其外框、配色与按钮样式，将字母改为 `F`；图片为 128×128 RGBA。
- 本适配包的 Modernity 材质、封面及其改编遵循上游 [LICENSE.txt](https://github.com/ModernityGTNH/Modernity-GTNH-UI/blob/2.9.X/LICENSE.txt) 标明的 [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/legalcode)，按许可提供，不附带担保。

## English

A Modernity-style resource pack for BetterFurnaceNH on Minecraft 1.7.10. Enable it above Modernity. The four 18×18 RGBA textures cover the furnace hopper input/output toggle states and are displayed at 16×16. The 128×128 RGBA cover adapts BackpackEnhance's Modernity button icon by changing its central letter from B to F.
